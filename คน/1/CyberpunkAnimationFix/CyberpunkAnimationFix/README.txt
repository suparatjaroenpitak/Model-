Unity 6: copy CyberpunkAnimationFix folder into Assets. Select Cyberpunk_Rigged_Fixed.fbx in Project. Rig: try Generic, Avatar Definition Create From This Model, Apply; Animation: Import Animation. Preview Run first. Menu Tools > Cyberpunk > Create Motion Controller from selected FBX. Assign generated controller to model Animator. Add CyberpunkMotionDriver to existing Player root, assign model Animator, Player CharacterController and movement root. Disable old CharacterAnimationBridge and other animation-only drivers, not movement scripts. Apply Root Motion off. Run threshold is actual m/s. If using a Rigidbody/custom movement system without CharacterController, this driver requires adaptation. Generic clips must match skeleton paths; if preview is frozen the FBX/rig requires repair; this package cannot repair missing curves. Not compiled/tested in Unity here.
