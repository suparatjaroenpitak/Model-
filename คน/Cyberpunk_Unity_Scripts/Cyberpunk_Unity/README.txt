Cyberpunk_Rigged.glb: actual skinned mesh, 26 joints, five procedural in-place clips.
Blender: File > Import > glTF 2.0; inspect Armature in Pose Mode, check weights and clips. Export FBX or run convert_to_fbx.py (requires locally installed Blender). Conversion not tested here.
Unity: import FBX, Rig > Humanoid > Create From This Model > Configure. Map all required bones and enforce T-pose; if Avatar fails use Generic and the included clips. Check texture import and normal map type; glTF packed metallic/roughness may need repacking for URP (metallic R, smoothness A = 1-roughness).
Animator Controller: make a 1D Blend Tree Locomotion with Speed parameter, Idle=0 Walk=1 Run=2. Add Grounded (bool), VerticalSpeed (float), Jump and Land (triggers). Jump transition from Any State when Jump, Land when Land, Land back to Locomotion with exit time. Enable Loop Time for Idle Walk Run only. Turn off Apply Root Motion. Attach CharacterAnimationBridge to existing player root and assign Animator and CharacterController. Existing movement code remains responsible for movement, gravity and jumping. Set walkSpeed/runSpeed to match it. For custom controller, call Drive each frame instead of using CharacterController.
Weights and animations are approximations, no finger bones, IK or facial rig. No Unity/Blender playback test in this environment. Original mesh positions, triangle count, UV and original PBR images preserved or repacked. Height normalized to 1.85m.
