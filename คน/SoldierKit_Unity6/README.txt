Unity 6: Copy Assets/SoldierKit into your project. Tools > AYUTTHAYA > Build Soldier. Generate Soldier Prefab. Drag generated prefab into existing player as visual child; disable old visual model. Assign an Animator Controller with compatible Humanoid clips. Model is T-pose and does not include animation clips or IK. Avatar validity displayed after generation. Each clothing piece is rigidly weighted to one bone; no smooth joint skinning. Rifle is a simplified game prop attached to right hand, not a real weapon model. For testing enable SoldierDemoInput on instance; disable it when connecting your own player. Call SoldierFire.Fire(direction) or FireForward() from existing input. Use Fire trigger optionally in controller. Aim/holding animation needed for two-handed pose. Built-in or URP intended; not tested in Unity. No scene creation. Textures are procedural, not photorealistic. No LOD or standalone AO/roughness maps. No player collider generated.
